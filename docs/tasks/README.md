# Remaining work

These files are the product requirements still to be built. Each file describes one capability: who it is for, what the hospital must remember, who may do it, and how to tell it is done.

The suggested pace is in [the intern roadmap](../intern-roadmap.md).

1. [Add a doctor](01-add-a-doctor.md) — record a doctor once, with a unique license number.
2. [View a doctor](02-view-a-doctor.md) — open one doctor that is already on file.
3. [Search doctors](03-search-doctors.md) — page through doctors and narrow the list by name.
4. [Update a doctor](04-update-a-doctor.md) — correct a doctor without breaking license uniqueness.
5. [Remove a doctor](05-remove-a-doctor.md) — remove a doctor who is no longer anyone's primary doctor.
6. [Tie patients to doctors](06-tie-patients-to-doctors.md) — a chart names a doctor the directory already knows.
7. [Register a patient chart](07-register-a-patient-chart.md) — open a chart under the chart field rules.
8. [View a patient chart](08-view-a-patient-chart.md) — a patient sees only their own chart.
9. [Search patients](09-search-patients.md) — page through charts and narrow by name or medical record number.
10. [Remove a patient chart](10-remove-a-patient-chart.md) — remove a chart that has no upcoming appointment.
11. [Book an appointment](11-book-an-appointment.md) — a patient books an existing doctor.
12. [Cancel an appointment](12-cancel-an-appointment.md) — cancelling frees that doctor's time.
13. [Review upcoming appointments](13-review-upcoming-appointments.md) — see appointments that are still ahead.
14. [Review accounts](14-review-accounts.md) — an administrator sees accounts, never passwords.
15. [Change a person's role](15-change-a-persons-role.md) — set someone to patient, doctor, or administrator.
16. [Suspend or restore an account](16-suspend-or-restore-an-account.md) — a suspended account cannot sign in.
17. [Renew a session](17-renew-a-session.md) — stay signed in without typing the password again.
18. [Review activity](18-review-activity.md) — see who changed doctors, charts, appointments, and accounts, and when.
19. [Slow repeated sign-in failures](19-slow-repeated-sign-in-failures.md) — repeated bad passwords are refused for a cooling-off period.
20. [Reset a forgotten password](20-reset-a-forgotten-password.md) — set a new password once, from a link that expires.
21. [Confirm an email address](21-confirm-an-email-address.md) — a new account cannot sign in until the email is confirmed.
